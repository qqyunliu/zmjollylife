# 视频审核 API 文档

## 1. 功能说明

本系统集成了基于阿里云的视频内容审核功能，通过抽取视频帧并调用阿里云 API 进行内容识别，实现对视频内容的自动审核。

## 2. 审核流程

1. **视频上传**：用户上传视频文件
2. **视频转码**：系统自动对视频进行转码处理
3. **帧提取**：转码完成后，系统每隔 5 秒抽取一帧视频画面
4. **AI 审核**：调用阿里云 API 对抽取的帧进行内容审核
5. **结果处理**：
   - 审核通过：视频状态变为 "审核成功/已发布"
   - 审核不通过：视频状态变为 "待人工复核"

## 3. API 接口

### 3.1 视频审核接口

**接口地址**：`/admin/video/audit`

**请求方法**：GET

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| videoId | String | 是 | 视频 ID |

**响应格式**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

**错误响应**：

```json
{
  "code": 600,
  "message": "视频不存在"
}

{
  "code": 600,
  "message": "视频状态不待审核"
}
```

**示例请求**：

```bash
GET /admin/video/audit?videoId=v123456
```

### 3.2 人工复核列表接口

**接口地址**：`/admin/video/review/list`

**请求方法**：GET

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNo | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 10 |

**响应格式**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "list": [
      {
        "videoId": "v123456",
        "videoName": "示例视频",
        "aiAuditStatus": 2,
        "aiAuditReason": "疑似AI生成内容",
        "status": 5,
        "statusName": "待人工复核",
        "createTime": "2024-01-01 12:00:00"
      }
    ],
    "totalCount": 1,
    "pageNo": 1,
    "pageSize": 10
  }
}
```

**示例请求**：

```bash
GET /admin/video/review/list?pageNo=1&pageSize=10
```

### 3.3 人工复核接口

**接口地址**：`/admin/video/review`

**请求方法**：GET

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| videoId | String | 是 | 视频 ID |
| action | String | 是 | 操作类型：pass（通过）、reject（拒绝） |
| reason | String | 否 | 拒绝原因（仅当 action=reject 时必填） |

**响应格式**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

**错误响应**：

```json
{
  "code": 600,
  "message": "视频不存在"
}

{
  "code": 600,
  "message": "视频状态不待复核"
}
```

**示例请求**：

```bash
# 通过审核
GET /admin/video/review?videoId=v123456&action=pass

# 拒绝审核
GET /admin/video/review?videoId=v123456&action=reject&reason=内容不符合规范
```

## 4. 视频状态说明

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| 0 | 转码中 | 视频正在转码 |
| 1 | 转码失败 | 视频转码失败 |
| 2 | 待审核 | 转码完成，等待 AI 审核 |
| 3 | 审核成功/已发布 | AI 审核通过，视频已发布 |
| 4 | 审核不通过 | 人工复核拒绝 |
| 5 | 待人工复核 | AI 审核不通过，等待人工复核 |

## 5. 审核结果说明

### 5.1 AI 审核状态

| 状态码 | 说明 |
|--------|------|
| 0 | 未审核 |
| 1 | 审核通过 |
| 2 | 审核不通过 |

### 5.2 人工复核状态

| 状态码 | 说明 |
|--------|------|
| 0 | 待复核 |
| 1 | 复核通过 |
| 2 | 复核拒绝 |

## 6. 阿里云配置

系统使用阿里云内容安全服务进行视频审核，需要在 `application.yml` 中配置：

```yaml
aliyun:
  access-key-id: your_access_key_id
  access-key-secret: your_access_key_secret
  region: cn-shanghai
```

## 7. 自动审核触发

系统会在视频转码完成后自动触发审核流程，无需手动调用审核接口。

## 8. 技术实现

### 8.1 帧提取

使用 FFmpeg 工具每隔 5 秒抽取一帧视频画面，最多抽取 10 帧。

### 8.2 审核调用

调用阿里云 `aigcDetectorForFrame` 接口对抽取的帧进行 AI 生成内容检测。

### 8.3 结果处理

- 任一帧审核不通过，则整个视频标记为不通过
- 所有帧审核通过，则视频标记为通过
- 审核完成后自动清理临时帧文件

## 9. 注意事项

1. **计费说明**：阿里云审核服务为付费服务，具体费用参考阿里云官网
2. **审核延迟**：视频审核可能会有一定延迟，取决于视频长度和阿里云 API 响应时间
3. **配置安全**：阿里云 AccessKey 请妥善保管，避免泄露
4. **错误处理**：审核过程中如遇到错误，系统会记录日志并继续运行

## 10. 故障排查

### 10.1 审核失败

- 检查阿里云 AccessKey 是否正确配置
- 检查网络连接是否正常
- 查看系统日志中的错误信息

### 10.2 帧提取失败

- 检查 FFmpeg 是否正确安装
- 检查视频文件是否损坏
- 查看系统日志中的错误信息

### 10.3 接口调用失败

- 检查视频 ID 是否正确
- 检查视频状态是否符合接口要求
- 查看系统日志中的错误信息
